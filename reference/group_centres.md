# Centres of the Named Groups

Centres of the Named Groups

## Usage

``` r
group_centres(nodes, group_names)
```

## Arguments

- nodes:

  Systems with x, y and community.

- group_names:

  Output of
  [`name_communities()`](https://stanstrup-metabolomics.github.io/rePredRet/reference/name_communities.md).

## Value

data.frame with group (letter), x and y (medians of its systems).

# Index Row from model.json

Index Row from model.json

## Usage

``` r
index_row_from_json(json_file)
```

## Arguments

- json_file:

  Path to a model.json written by
  [`export_model_json()`](https://stanstrup-metabolomics.github.io/rePredRet/reference/export_model_json.md)

## Value

One-row data.frame with the index columns

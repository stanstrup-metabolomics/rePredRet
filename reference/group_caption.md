# Caption Naming the Groups

Caption Naming the Groups

## Usage

``` r
group_caption(group_names)
```

## Arguments

- group_names:

  Output of
  [`name_communities()`](https://stanstrup-metabolomics.github.io/rePredRet/reference/name_communities.md).

## Value

One line per named group ("A: name"), or a generic caption.

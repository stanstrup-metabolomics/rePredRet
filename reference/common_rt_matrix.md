# Common Compound RT Matrix from Lookups

Common Compound RT Matrix from Lookups

## Usage

``` r
common_rt_matrix(lookup1, lookup2)
```

## Arguments

- lookup1, lookup2:

  Elements of
  [`prepare_rt_lookup()`](https://stanstrup-metabolomics.github.io/rePredRet/reference/prepare_rt_lookup.md)
  output

## Value

Matrix like
[`get_common_compounds()`](https://stanstrup-metabolomics.github.io/rePredRet/reference/get_common_compounds.md)
